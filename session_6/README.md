# Session 6 — Inheritance and Polymorphism

- `assignment/RaceEntryFoundation.java`: validated base class, inheritance, overriding, classification, batch validation and polymorphic balances.
- `assignment/RaceDayAnnouncerBoard.java`: polymorphic announcements for mixed entry types.
- `assignment/RaceSettlementEngine.java`: unique IDs, promo discounts and nightly settlement demonstration.
- `practice/TicketHierarchyFoundation.java`: ticket hierarchy and batch validation.
- `practice/NightlyTicketAnnouncer.java`: mixed ticket announcement.
- `practice/FestSettlementEngine.java`: ticket IDs, promo codes and settlement.

Each Java file is self-contained. Compile with `javac FileName.java` and run with `java FileName`.
